Unit Converter API

API REST para conversión de unidades de distancia, temperatura y peso.

1. Distancia

Unidades: metros, kilometros, centimetros, millas, yardas, pies, pulgadas

GET /api/convert-distance?value=5&from=kilometros&to=millas

2. Temperatura

Unidades: celsius, kelvin, fahrenheit

GET /api/convert-temperature?value=100&from=celsius&to=fahrenheit

3. Peso

Unidades: kilos, gramos, toneladas, libras, onzas

GET /api/convert-weight?value=10&from=kilos&to=libras
